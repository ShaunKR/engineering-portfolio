# 아키텍처 다이어그램

Mermaid 코드 블록을 프로젝트 또는 기술 문서에 직접 작성합니다. 여러 문서에서 공유할 설명은 이 폴더의 별도 `.md` 파일로 분리하고 상대경로로 연결합니다.

아래는 문법 안내용 가상 예시입니다. 실제 프로젝트 구성이나 수행 경험을 의미하지 않습니다.

```mermaid
flowchart LR
    Client[클라이언트] --> API[애플리케이션]
    API --> DB[(데이터 저장소)]
```

실제 설계를 작성할 때는 구성 요소, 통신 방향, 데이터 흐름, 경계와 주요 제약을 설명합니다. 내부 호스트명, IP, 계정 및 고객 식별 정보는 포함하지 않습니다.
