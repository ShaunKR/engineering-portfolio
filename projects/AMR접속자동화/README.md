# [automation] macOS에서 AMR SSH 접속 자동화

여러 AMR을 관리하면서 반복하던 IP 조회와 SSH 접속 명령을 zsh 함수로 묶어 사용했다. 로봇 번호만 입력해 주소를 찾아 접속하거나, 현장의 네트워크 규칙에 맞춰 접속 대상을 지정할 수 있도록 했다.

## 작업 목적

로봇마다 IP와 SSH 명령을 기억하거나 매번 목록에서 찾아 입력하는 반복 작업을 줄이는 것이 목적이었다. Mac의 `.zshrc`에 접속 함수를 등록해 터미널에서 짧은 명령으로 사용할 수 있게 했다.

## 실제 사용했던 방식

- 로봇 번호를 `R_001` 형식의 ID로 변환한다.
- 현장별 로봇 목록에서 ID에 대응하는 IP를 찾는다.
- SSH 키와 계정으로 해당 AMR에 접속한다.
- IP를 직접 지정하거나, 원격 호스트의 포트를 지정하는 접속도 지원한다.
- 네트워크 대역과 로봇 번호의 규칙을 이용하는 현장별 접속 함수도 사용했다.

포트 지정 함수는 이미 제공된 원격 접속 경로를 사용하는 클라이언트 기능이다. 중계 서버, 터널 생성 또는 AMR 원격 관리 서버를 구축하는 코드가 아니다.

## 공개 자료

- [zsh 접속 함수](amr-tools.zsh)
- [로봇 목록 예시](hosts.example.tsv)

개인 `.zshrc` 전체를 공개하지 않고 AMR 접속 기능만 별도 파일로 재작성했다. 실제 현장·고객사 표기, 주소, 계정명, 원격 도메인과 개인 경로를 예시 설정으로 바꿨다. 실제 로봇 목록과 SSH 키는 포함하지 않는다.

## 원본과 공개본의 차이

| 원본 함수 | 원래 용도 | 공개본 |
| --- | --- | --- |
| `go` | 로봇 번호로 IP를 찾아 SSH 접속 | `amr_go` |
| `wr` | 로봇 번호에 해당하는 IP 조회 | `amr_ip` |
| `key_sr`, `sr` | IP를 지정해 SSH 키로 접속 | `amr_ssh` |
| `p2p_sr`, `r1` | 원격 호스트의 포트를 지정해 접속 | `amr_remote` |
| 현장별 주소 조합 함수 | 대역과 로봇 번호로 대상 주소 구성 | 실제 대역이 포함되어 공개본에서 제외 |

공개본에서는 개인 절대경로를 설정 변수로 분리하고, 인자·목록 파일·키 파일 확인과 함수 내부 변수 범위를 보완했다. 원본 함수명은 기존 셸 명령과 충돌할 수 있어 `amr_` 접두사로 변경했다. 이 보완 내용을 과거 현장 사용본과 동일한 구현으로 설명하지 않는다.

## 설정과 사용

zsh에서 파일을 읽기 전에 실제 환경의 설정값을 지정한다. 파일을 읽는 것만으로 SSH 접속이 시작되지는 않는다.

```zsh
export AMR_HOSTS_FILE="$HOME/.config/amr/hosts.tsv"
export AMR_SSH_USER="amr"
export AMR_IDENTITY_FILE="$HOME/.ssh/id_ed25519_amr"
export AMR_REMOTE_HOST="remote.example.com"
source ./amr-tools.zsh
```

로봇 목록은 공백 또는 탭으로 ID와 IP를 구분한다. 예시 파일을 실제 목록으로 바꿔 지정한 위치에 준비한다.

```text
R_001  192.0.2.11
R_002  192.0.2.12
```

위 주소와 도메인은 문서용이며 실제 접속 대상이 아니다.

```zsh
amr_ip 1              # R_001의 IP만 출력
amr_go 1              # R_001에 SSH 접속
amr_ssh 192.0.2.11     # 주소를 직접 지정
amr_remote 22001       # 준비된 원격 호스트의 포트로 SSH 접속
```

기존 `.zshrc`에는 실제 파일 경로로 `source` 한 줄을 추가해 사용할 수 있다. SSH 키와 서버 접근 권한은 별도로 준비한다. 호스트 키 검증과 비밀번호 인증 여부는 사용자의 SSH 설정을 따르며 검증 생략 옵션은 추가하지 않았다.

## 결과와 검증

실제 AMR 관리에 사용했던 접속 단축 명령을 공개 가능한 형태로 정리했다. 로봇 번호 기반 조회와 접속 명령을 통해 반복 입력을 줄이는 방식이다. 시간 절감 수치를 별도로 측정한 기록은 제시하지 않는다.

공개본은 zsh 구문 검사와 가짜 SSH 함수를 이용한 로컬 검증을 수행했다. 로봇 목록 조회, 미등록 번호 처리, 직접·원격 접속 인자와 포트 범위를 확인했다. 실제 SSH 명령이나 AMR 접속, 로봇 제어는 실행하지 않았다.

이 스크립트는 SSH 접속 편의 도구이며 여러 로봇에 대한 병렬 명령 실행, 상태 수집, 재시작이나 이동 제어 기능은 포함하지 않는다.
