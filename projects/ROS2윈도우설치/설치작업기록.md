# ROS 2 Windows 설치 작업 기록

제공된 설치 메모를 Markdown으로 옮긴 과거 작업 기록이다. Qt 로그인 정보는 제거했다. 명령은 당시 버전 기준이며 현재 설치를 재검증한 절차가 아니다. 경로와 미확인 항목은 [설치 가이드](윈도우설치가이드.md)를 함께 확인한다.

```text
설치 참조 URL
https://docs.ros.org/en/humble/Installation/Alternatives/Windows-Development-Setup.html#
설치환경  : window 11

영문 언어팩 설치 후 영문을 기본으로 설정(한글로 진행시 에러가 발생함.. 정확한 원인은.. 음..)->한글로 설치시 더 확인 필요

1. Install Chocolatey
 PowerShell을 관리자 권한으로 오픈
 Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))
 명령어 실행
 
2. Install Python
 명령 프롦프트 Open 
 choco install -y python --version 3.8.3
 설치 완료 후 reboot필요
 
3. Install Visual C++ Redistributables
 명령 프롦프트 Open
 choco install -y vcredist2013 vcredist140
 
4. Install OpenSSL
 명령 프롦프트 Open
 choco install -y openssl --version 1.1.1.2100
 시스템 환경변수 사용자 변수에 OPENSSL_CONF환경 변수가 등록되어 있는지 확인
 아래는 환경변수 등록 명령어
 setx /m OPENSSL_CONF "C:\Program Files\OpenSSL-Win64\bin\openssl.cfg"
 
5. Install Visual Studio
 Install Visual Studio 2019.
 vs_community_2019.exe 실행
 c++ cmake도구 선택 해제 및 설치
 
6. Install OpenCV
 opencv-3.4.6-vc16.VS2019 폴더내 opencv폴더를 C:\opencv 로 복사
 setx /m OpenCV_DIR C:\opencv 로 환경변수 등록(시스템 변수)
 PATH 에 C:\opencv\x64\vc16\bin 추가 (참고 Lenovo에는 미등록 되어 있음. 확인 필요)
 
7. Install dependencies
 명령 프롦프트 Open
 cmake-3.16.9-win64-x64 실행
 C:\Program Files\CMake\bin to your PATH.
 
 package폴더를 c:\에 복사
 administrative shell  오픈
 c루트로 이동
 choco install -y -s package asio cunit eigen tinyxml-usestl tinyxml2 bullet 
 
 First upgrade pip and setuptools:
 python -m pip install -U pip setuptools==59.6.0
 
 Now install some additional python dependencies:
 python -m pip install -U catkin_pkg cryptography empy importlib-metadata lark==1.1.1 lxml matplotlib netifaces numpy opencv-python PyQt5 pillow psutil pycairo pydot pyparsing==2.4.7 pyyaml rosdistro
 설치 에러시 다시 실행 하면 설치 완료 됨
 
8. Install Qt5
 qt-opensource-windows-x86-5.12.12 실행
 MSVC 2017 64-bit 체크
 
 setx /m Qt5_DIR C:\Qt\Qt5.12.12\5.12.12\msvc2017_64
 setx /m QT_QPA_PLATFORM_PLUGIN_PATH C:\Qt\Qt5.12.12\5.12.12\msvc2017_64\plugins\platforms

 RQt dependencies
 windows_10_cmake_Release_graphviz-install-12.0.0-win64 실행
 
 
9. Additional prerequisites
 9.1 Install additional prerequisites from Chocolatey 
   choco install -y cppcheck curl git winflexbison3
 9.2 Install Python prerequisites
   pip install -U colcon-common-extensions coverage flake8 flake8-blind-except flake8-builtins flake8-class-newline flake8-comprehensions flake8-deprecated flake8-docstrings flake8-import-order flake8-quotes mock mypy==0.931 pep8 pydocstyle pytest pytest-mock vcstool
 9.3 Install miscellaneous prerequisites
   xmllint 폴더를 c\로 복사
   시스템변수 Path 에 C:\xmllint\bin 추가
   
10. Get the ROS 2 code
  긴 패스명 설정
  https://learn.microsoft.com/en-us/windows/win32/fileio/maximum-file-path-limitation?tabs=registry
  powerShell
  New-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem" `
-Name "LongPathsEnabled" -Value 1 -PropertyType DWORD -Force

  폴더 생성
  md dev\humble\src
  cd dev\humble
  
  x64 native tools command prompt for vs 2019 실행
  vcs import --input https://raw.githubusercontent.com/ros2/ros2/humble/ros2.repos src
  
  colcon build --merge-install
  ///////////////////// Error 
  AttributeError processing template 'msg.idl.em'

  Traceback (most recent call last):

    File "D:\dev\ros2_humble\install\Lib\site-packages\rosidl_adapter\resource\__init__.py", line 51, in evaluate_template
      em.BUFFERED_OPT: True,

  AttributeError: module 'em' has no attribute 'BUFFERED_OPT'



  During handling of the above exception, another exception occurred:  에러 해결 방법은
  
  empy 구버전 사용 (대체 방법): 만약 최신 버전으로도 문제가 해결되지 않는다면, ROS2에서 호환되는 구버전 empy==3.3.4를 설치해 보세요. 일부 환경에서는 최신 버전이 오히려 호환성 문제를 일으킬 수 있습니다.
  pip install empy==3.3.4 
  ///////////////////////////////



Visual Studio 2019 Developer Command Prompt:

call \dev\ros2_humble\install\local_setup.bat
md \dev\ros2_dotnet_ws\src
cd \dev\ros2_dotnet_ws
curl -sk https://raw.githubusercontent.com/ros2-dotnet/ros2_dotnet/main/ros2_dotnet_humble.repos -o ros2_dotnet_humble.repos 안되면 ros2_dotnet_humble.repos 파일을 dev\ros2_dotnet_ws 에 복사
vcs import src < ros2_dotnet_humble.repos
git clone --branch humble https://github.com/ros2/rosidl src\ros2\rosidl
colcon build --merge-install

  
```
