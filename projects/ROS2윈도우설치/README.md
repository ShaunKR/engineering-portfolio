# [robotics] ROS 2 Humble Windows 설치 가이드

Windows 11에서 ROS 2 Humble 개발 환경을 설치하고 소스 빌드하는 과정의 작업 메모를 정리했다. Windows 도구 체인과 의존성 설치, 환경변수 설정, 빌드 오류 대응 및 ros2_dotnet 연동 절차를 담는다.

## 공개 자료

- [Windows 설치 가이드](윈도우설치가이드.md): 설치 순서와 환경별 확인 사항
- [설치 작업 기록](설치작업기록.md): 제공된 과거 메모를 Markdown으로 옮긴 자료. 로그인 정보 제거

## 기록된 환경

| 항목 | 당시 메모의 버전 |
| --- | --- |
| OS | Windows 11 |
| ROS 2 | Humble, 소스 빌드 |
| Python | 3.8.3 |
| Visual Studio | 2019 |
| OpenSSL | 1.1.1.2100 (Chocolatey 패키지 버전) |
| OpenCV | 3.4.6, VS2019용 파일 |
| CMake | 3.16.9 |
| Qt | 5.12.12, MSVC 2017 64-bit 구성 요소 |
| 빌드 도구 | vcstool, colcon |

이는 현재 권장 버전 목록이 아니라 당시 작업 환경의 기록이다. 원본 메모는 영문 언어 환경 사용과 `empy` 호환성 오류를 함께 기록한다.

## 작업과 공개 범위

- Windows 개발 도구와 ROS 2 빌드 의존성 설치 절차 정리
- 환경변수와 긴 경로 설정 기록
- `em.BUFFERED_OPT` 오류에 대한 `empy==3.3.4` 대응 방법 기록
- ROS 2 기반 .NET 연동 워크스페이스 구성·빌드 명령 기록

이번 등록 과정에서는 Windows 설치, ROS 2 빌드, 노드 통신 및 .NET 연동을 재시험하지 않았다. 원본에 완료 로그가 없으므로 전체 빌드 성공이나 통신 성공을 검증 결과로 추가하지 않는다. 설치 파일과 로컬 의존성 패키지 원본은 포함하지 않는다.
