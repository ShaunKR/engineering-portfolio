# 주요 프로젝트

아직 등록된 프로젝트가 없습니다. 아래 템플릿을 `프로젝트명.md` 파일로 복사하고, 작성한 문서를 이 목록에 연결합니다.

## 프로젝트 문서 템플릿

```markdown
# 프로젝트명

## 개요
- 기간:
- 서비스 또는 업무 영역:
- 목표:
- 팀 구성: 공개 가능한 범위에서 작성

## 역할과 기여
- 본인 담당 범위:
- 협업 및 의사결정 범위:

## 기술 환경
- 언어 및 런타임 버전:
- 프레임워크 및 빌드 도구:
- 데이터 저장소 및 메시징:
- 배포 및 운영 환경:

## 주요 과제
- 해결해야 했던 문제:
- 요구사항과 제약:

## 아키텍처와 설계 판단
- 구성 요소와 데이터 흐름:
- 검토한 대안:
- 선택 이유와 감수한 단점:

## 해결 과정
- 분석 및 검증:
- 구현 내용:
- 테스트 및 적용 과정:

## 성과와 한계
- 확인된 결과:
- 측정 조건과 근거: 수치를 제시하는 경우 작성
- 남은 제약 및 개선점:

## 관련 문서
- 기술 위키:
- 트러블슈팅:
```

아키텍처는 문서에 Mermaid 코드 블록으로 작성합니다. 예시는 [다이어그램 안내](../../assets/diagrams/README.md)를 참고합니다.
