# 트러블슈팅

아직 등록된 사례가 없습니다. 확인된 장애 또는 문제 해결 사례를 아래 양식으로 작성하고 목록에 연결합니다. 파일명은 `문제-주제.md` 형식을 사용합니다.

## 사례 문서 템플릿

```markdown
# 문제 제목

## 상황과 영향
- 발생 시점 또는 기간: 공개 가능한 수준으로 작성
- 환경 및 버전:
- 증상:
- 확인된 영향 범위:
- 본인의 역할:

## 분석 과정
- 확인한 증거: 기밀을 제거한 요약만 사용
- 가설:
- 검증 방법과 결과:
- 배제한 원인과 근거:

## 원인
- 확인된 원인:
- 아직 확인되지 않은 부분:

## 해결 과정
- 임시 조치:
- 근본 조치:
- 적용 및 롤백 판단:

## 결과 검증
- 검증 방법과 관찰 기간:
- 확인된 결과:
- 남은 한계:

## 재발 방지
- 추가한 테스트 또는 모니터링:
- 운영 절차 변경:
- 후속 작업과 완료 여부:

## 관련 문서
- 프로젝트:
- 기술 위키:
```

시간 순서가 분석에 중요하면 타임라인을 추가합니다. 미확인 원인을 확정적으로 서술하지 않습니다.
